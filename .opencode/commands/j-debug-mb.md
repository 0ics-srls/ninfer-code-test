# j-debug-mb (compact variant of j-debug)

This command is identical to **j-debug** — the ONLY difference is the mindset file: it loads the MBEL-compact `debug-protocol-mb.md` (~70% fewer tokens) instead of the verbose `debug-protocol.md`.

## What to do

1. Read `.opencode/commands/mind-sets/debug-protocol-mb.md` (if not read this session) — NOT the verbose debug-protocol.md
2. Read `.opencode/commands/j-debug.md` and follow it EXACTLY, skipping its `debug-protocol.md` prerequisite (you already loaded the compact variant)

All steps, rules, and dialogs are defined in j-debug.md — single source of truth.
